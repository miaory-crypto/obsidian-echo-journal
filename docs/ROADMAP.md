# Roadmap

这是候选方向，不是承诺的发布日期。

## Release readiness

- 在合成 Vault 中验证安装、索引、选区检索、收藏和对话开关。
- 增加对网络请求与持久化边界的自动测试。
- 为聊天记录和收藏提供应用内删除/导出控制。
- 在发布前再次运行密钥、路径和大文件扫描。

## Reliability

- 增量索引，只重新计算新增或修改的文件。
- 查询与 AI 结果缓存。
- 更明确的诊断页和错误分类。
- 可取消的远端请求与重试去重，降低重复计费风险。

## Retrieval quality

- 在普通语义近邻之外，探索对照、反例、观点变化和结构相似性。
- 把模型提出的关系明确标为候选解释，并保留来源证据。
- 用合成基准和自愿提供的匿名反馈评估召回与排序；不开源真实私人笔记。

## Distribution

- 创建带有三个插件运行文件和安装 ZIP 的 GitHub Release。
- 稳定后再评估 Obsidian Community Plugins 提交；届时按其要求调整根目录 manifest 与版本文件。

## Non-goals for now

- 自动修改原始笔记。
- 自动把模型结论写入长期记忆。
- 把一次文本相似性解释为稳定的人格模式。
- 无范围限制地上传整个 Vault。

# Changelog

## Unreleased — public repository hardening

- 默认 embedding 改为本机 Ollama；AI 解释与聊天默认关闭。
- 外部 embedding 运行前必须设置笔记文件夹，避免误传整个 Vault。
- embedding key 与引导/聊天 key 完全分离，不再跨服务复用。
- 外部 Bearer key 仅允许发往 HTTPS 或本机 loopback 地址。
- 模型回复改为纯文本显示，避免远程 Markdown 资源产生额外请求。
- 限制 sidecar 为 Vault 内安全相对目录。
- 增加公开隐私说明、安装文档、合成示例、CI、发布打包、贡献与安全政策。
- 移除私人项目手册、旧 Python 测试和与核心插件无关的个人数据转换工具。

## 0.8.5 — candidate

- 支持选中文字后直接检索相关片段。
- 同一笔记中的不同选区使用独立查询与对话身份，查询 key 不包含选中原文。
- 增加可绑定快捷键的选区检索命令。
- 核心纯函数测试增至 18 组。

## 0.8.4 — candidate

- 聊天失败或超时后支持原位重试。
- `Enter` 发送、`Shift + Enter` 换行，并避开输入法组合状态。
- 检索结果支持复制完整片段。

## 0.8.3 — candidate

- 缩短连续对话 Prompt，取消每轮必须提问和固定认知动作。
- 保留来源边界、提示注入防护和“弱相关时不强行引用”的约束。

## 0.8.2 — candidate

- 打开检索结果或聊天来源时定位并高亮匹配片段。
- 删除固定尖锐话术；只有存在具体证据时才提出反对或矛盾。

## 0.8.1 — candidate

- 首次进入对话时由 ECHO 主动开场。
- 增加“开始新对话”，旧会话归档而非直接删除。

## 0.8.0 — candidate

- 增加基于当前文本、相关旧片段和近期历史的连续对话。
- 对话按 `user` / `assistant` 分层保存到 sidecar，不写入原笔记。
- 增加超时、HTTP 错误、空响应提示和来源列表。

## 0.7.0

- 收藏具体片段并添加个人标注。
- 在新标签页打开来源，保持结果面板与当前查询上下文。
- 增加“查看已收藏的重要片段”和“返回本次笔记”。

## 0.6.0

- AI 解释改为按需按钮，不再自动调用。

## 0.5.0

- 增加克制的相关性解释；AI 失败时保留基础检索结果。

## 0.4.x

- 增加 Ollama 批量 embedding、索引进度、结果面板复用与错误提示。

## 0.3.x

- 使用 Obsidian `requestUrl` 调用可配置的 OpenAI-compatible API。

## 0.2.0

- 建立当前 Obsidian 插件原型：目录范围、片段切分、相似检索和基础错误处理。

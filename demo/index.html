03 / BYOK 与隐私

API key 留给使用者自己掌控

项目不附带开发者密钥，也不经过项目方的中转服务器。你可以完全不填 key；只有启用外部能力时，才使用你向相应服务商申请的凭据。

默认本地检索
Ollama 模式不需要 API key。笔记片段会发给你配置的 Ollama 地址，默认是本机 127.0.0.1。
外部 embedding
只使用单独的 embedding endpoint 与 key；只有明确设置日记文件夹后才能运行，避免误索引整个 Vault。
AI 解释与聊天
默认关闭。只有你主动开启并点击，才把当前文本、候选片段和近期对话发给单独配置的 guidance/chat API。
不会自动复用
插件不会把 embedding key 自动复制、回退或复用于对话功能。服务商条款、隐私政策与可能产生的费用由用户自行确认。
Key 存在哪里？为什么不能提交到 GitHub？

Key 会以明文保存在 Vault 的 .obsidian/plugins/diary-review/data.json，可能随 Vault 同步或系统备份被复制。公开仓库只提供空字段示例，并用 .gitignore 排除 data.json、.env、索引与常见密钥文件；你仍需避免把真实设置、日志或截图上传到 issue。
